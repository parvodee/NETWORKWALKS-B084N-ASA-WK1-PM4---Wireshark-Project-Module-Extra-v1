# NETWORKWALKS-B084N-ASA-WK1-PM4-Wireshark-Project-Module-Extra-v1
I'm looking into six live labs for this project. where ten tasks and a network capture are provided by each lab. I use my knowledge of Wireshark to identify the answers, including passwords, secret data, attackers, and scam calls.

 Project Objectives

- Analyse network traffic to identify suspicious IP addresses.

- Reconstruct network conversations using TCP stream analysis.

- Investigate hidden information in captured traffic.

- Identify credentials transmitted in clear text over HTTP.

- Recognise patterns associated with brute-force attacks.

- Investigate VoIP traffic and suspected scam calls.
  

** Resources and Instruments**

- Wireshark: Packet inspection and network protocol analysis.
- PCAP files: Network traffic that has been recorded for use in an investigation.
